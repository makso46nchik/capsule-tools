CAPSULE TOOLS
Документация
Версия: 1.0

О ПРОЕКТЕ

Capsule Tools — открытая утилита с дополнительными функциями для VK Капсулы Мини после получения доступа к системе.

Проект создан как независимая community-разработка и не связан с VK или Маруся.

ВОЗМОЖНОСТИ

• Часы — отображение текущего времени.
• Погода — получение информации о погоде.
• Громкость — управление уровнем громкости устройства.
• Таймер — запуск обратного отсчёта.
• Монитор устройства — просмотр основной системной информации.
• Wi-Fi — просмотр информации о сетевом подключении.
• Перезапуск — быстрый перезапуск устройства.
• Единая панель — доступ к функциям из одного места.

ТРЕБОВАНИЯ

Перед установкой убедитесь, что:

1. На устройстве уже получен необходимый доступ к системе.
2. Есть возможность запускать пользовательские файлы/скрипты.
3. Устройство подключено к сети, если используются сетевые функции.
4. Вы понимаете, что стороннее ПО может работать нестабильно.

ВАЖНО

Capsule Tools не является официальным ПО VK.
Используйте проект на свой риск.
Не изменяйте системные файлы без необходимости.
Перед экспериментами рекомендуется сохранить резервные копии важных конфигураций.

УСТАНОВКА

1. Скачайте исходный код проекта:
   https://github.com/makso46nchik/capsule-tools

2. Распакуйте проект на устройство.

3. Изучите файлы проекта и инструкцию INSTALL/README, если они присутствуют в используемой версии.

4. Запустите установочный скрипт проекта, если он предусмотрен конкретной сборкой.

5. После установки перезапустите утилиту или устройство.

ЗАПУСК

После установки запустите основной файл Capsule Tools способом, указанным в README проекта.

Если в вашей сборке используется единая панель, после запуска из неё доступны основные функции:
часы, погода, громкость, таймер, мониторинг, Wi-Fi и перезапуск.

НАСТРОЙКА

Настройки зависят от конкретной версии сборки.

Перед изменением параметров рекомендуется проверить README и конфигурационные файлы проекта.

ПОГОДА

Для получения погоды требуется сетевое подключение.
Если сервис погоды не отвечает, проверьте интернет-соединение и настройки сетевого доступа.

WI-FI

Раздел Wi-Fi предназначен для просмотра информации о текущем сетевом подключении.

Не передавайте сторонним людям пароли и другие данные доступа к своей сети.

МОНИТОРИНГ

Монитор устройства может использоваться для просмотра базовой информации о состоянии системы, например загрузки процессора, памяти и других доступных параметров.

Набор показателей зависит от возможностей системы и версии сборки.

ПЕРЕЗАПУСК

Функция перезапуска выполняет обычную перезагрузку устройства средствами системы.

Не используйте перезапуск во время обновления или записи важных системных файлов.

УДАЛЕНИЕ

Для удаления используйте uninstall-скрипт, если он входит в вашу версию проекта.

Если отдельного скрипта удаления нет, удаляйте только файлы Capsule Tools и не затрагивайте системные файлы устройства.

ОШИБКИ

Если утилита не запускается:

1. Проверьте права на запуск файлов.
2. Проверьте зависимости.
3. Проверьте путь к файлам проекта.
4. Проверьте сетевое подключение для сетевых функций.
5. Посмотрите сообщения об ошибках в терминале.

Если проблема сохраняется, приложите текст ошибки при создании issue на GitHub.

ОБНОВЛЕНИЕ

Перед обновлением рекомендуется сохранить текущую конфигурацию.

Скачайте новую версию проекта и следуйте инструкции, указанной в README соответствующего релиза.

РАЗРАБОТКА

Проект распространяется открыто. Предложения по новым функциям, исправлениям и улучшениям можно отправлять через GitHub.

Идеи для будущих версий:

• дополнительные системные показатели;
• расширенные сетевые инструменты;
• настройка интерфейса;
• дополнительные таймеры;
• новые инструменты управления устройством.
